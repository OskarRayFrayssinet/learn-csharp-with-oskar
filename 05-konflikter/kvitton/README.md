# Kvitton

Här hamnar ett kvitto för varje scenario i Konfliktlabbet som du har löst.
Kvittona skapas automatiskt när `kontrollera` går igenom.

**Committa och pusha kvittona**, så syns de i autorättningen och på din dashboard:

```powershell
git add 05-konflikter/kvitton
git commit -m "Konfliktlabbet: scenario 1–3"
git push
```

Ändra inte i kvittona för hand. Autorättningen kontrollerar innehållet igen.
